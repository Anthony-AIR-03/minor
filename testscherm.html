Je game aansluiten op opslag

Test eerst de API. Sluit daarna je bestaande game aan. Gebruik verzonnen codes; deze oefenomgeving heeft geen gebruikerslogin.

Kleine letters, cijfers en koppeltekens. Met dezelfde code kun je resultaten na herladen terugvinden. Iedereen die die code kent kan de demoresultaten opvragen.

2. Test opslaan zonder game

De testknop bewaart 2 van 3 punten voor verbindingstest. Klik daarna op teruglezen en controleer ook de rij in phpMyAdmin.

3. Test je bestaande single-file game

Neem de game-id uit de gamestekker exact over. Het testscherm opent de game op jouw eigen website en bewaart het GAME_COMPLETED-bericht. De losse game roept de API niet aan.
